Documente le terme ou la notion suivante dans le vault Obsidian : $ARGUMENTS

Invoque le skill `doc` et suis-le de bout en bout. En résumé :

1. **Placement** via `obsidian-management` — connaissance transférable → `~/vault/Notes/` (à plat). Doute ou spécifique projet → consulter `obsidian-management`.
2. **Ne pas dupliquer** : si une note existe déjà sur ce terme, la mettre à jour ; si c'est un sous-concept très proche d'une note existante, l'y intégrer (granularité hybride).
3. **Rattacher au set thématique** : poser le tag de thème (`#music`, …), pointer `out:` vers le MOC du thème s'il existe, et **ajouter la note dans le MOC** (bonne section).
4. **Écrire** en français, prose, jargon expliqué (`style-reponse`), ton neutre/référence : définition en une phrase, explication, `## En pratique` si utile, `## Voir aussi` avec les `[[liens]]`.
5. **Câbler les liens** dans les deux sens (MOC + notes voisines), **vérifier qu'aucun `[[...]]` n'est mort**, ne pas commiter le vault.
6. **Confirmer** où la note a été créée/mise à jour et quels liens ont été ajoutés.

Si plusieurs termes sont demandés, traiter chacun comme une note (ou les regrouper si ce sont des sous-concepts inséparables).
