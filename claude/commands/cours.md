Fais un cours pédagogique et autoportant sur le sujet suivant : $ARGUMENTS

Invoque le skill `cours` et suis-le de bout en bout. En résumé :

1. **Placement** via `obsidian-management` — transférable → `~/vault/Notes/` ; spécifique projet → `projects/<projet>/etudes/` (avec `in: [[projet]]` + lien depuis le hub).
2. **Ne pas dupliquer** : si une note existe déjà sur le sujet, l'étendre.
3. **Écrire de zéro**, en français, prose pédagogique (`style-reponse`), progressif et illustré : « De quoi il s'agit », les fondations, comment ça marche, cas d'usage, pièges courants, `## Voir aussi`, `## Références`.
4. **Câbler les liens** (notes voisines / hub projet), **vérifier qu'aucun `[[...]]` n'est mort**, ne pas commiter le vault.
5. **Confirmer** où la note a été créée/mise à jour et quels liens ont été ajoutés.

Pour une note de **référence courte** sur un terme d'un domaine déjà suivi (tag + MOC), utiliser plutôt `/doc`.
